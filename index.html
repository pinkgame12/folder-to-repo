GitHub repo import tool

Copy one folder from an existing repo into a brand-new repo.

Paste a GitHub folder URL, authenticate with a token that has permission to read the source repo and create repos in the destination org or account, and the app will create a new repository named after the folder and copy every file into it.

Import settings

The safest setup is a fine-grained personal access token or GitHub App installation token. For a public website, put this behind a backend so the token never reaches the browser.

Needs repo read access on the source repo and repo creation permission on the target org/account.
This app accepts URLs in the form /tree/branch/folder or /blob/branch/file. For a file link, it will import just that file.
Requirements: the token must have permission to create repositories in the target owner/org. Some orgs require SSO authorization or approval for the token or app installation.
