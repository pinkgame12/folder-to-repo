GitHub repo import tool

Copy one folder from an existing repo into a brand-new repo.

Paste a GitHub folder URL, authenticate with a token that can read the source repo and create repos in the destination account or organization, and the app will create a new repository named after the folder and copy every file into it.

Import settings

Use a fine-grained personal access token or GitHub App installation token. For a public site, move the GitHub calls to a backend so the token never reaches the browser.

In Entire Repo mode, each top-level folder becomes its own new repository. The repository name is exactly the folder name.
Select a preset to auto‑fill token and target owner. Token is never stored in this page.
Needs source repo read access and repo creation permission on the target owner or org.
Single Folder mode accepts /tree/branch/folder or /blob/branch/file. Entire Repo mode accepts a repository URL such as https://github.com/owner/repo or its /tree/branch URL.

Select folders to clone

Load the repository first, then select exactly which top-level folders should become repositories.

Enter a repository URL, then click Load folders.
If you are creating repos inside an organization, your account must already have permission to create repositories there. A token alone cannot bypass org-level access rules.
